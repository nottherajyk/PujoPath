# PujaPath

Mobile-first Kolkata Durga Puja guide: pandal directory, zone hopping, route planner, wishlist, metro lines/stations and a metro map. Plain HTML/CSS/JS, generated by a small Node script (no dependencies).

## Edit content
- `data.mjs` — site config (email, Instagram, domain), metro lines, zones and all pandals (one line per pandal).
- Photos: drop `<pandal-id>.jpg` (or .webp/.png) into `src/assets/pandals/`. The id is the slug, e.g. `maddox-square.jpg`. Cards and pages pick it up automatically.
- Replace placeholders in `data.mjs`: `SITE.url`, `SITE.email`, `SITE.instagram`, `SITE.instagramUrl`.

## Build and run
```
node build.mjs          # writes public/
npx serve public        # preview
```

## Deploy (Vercel)
Import the folder as a project. `vercel.json` already sets `buildCommand: node build.mjs` and `outputDirectory: public`.
After deploying, set `SITE.url` to the real domain and rebuild so canonical URLs, Open Graph tags and the sitemap are correct. Then submit `/sitemap.xml` in Google Search Console.
